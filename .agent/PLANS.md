# 计划规则

任何跨模块或多阶段修改都必须使用执行计划。计划必须说明范围、不变量、验证方式，以及回滚或恢复注意事项。完成验证后应立即更新状态；绝不能只根据代码检查就把 Phase 标记为通过。

允许的 Phase 状态只有 `TODO`、`IN_PROGRESS`、`PASS` 和 `BLOCKED`。每个 Phase 都要记录已实现内容、测试、问题、修复和剩余事项。未运行的环境相关检查必须在报告中明确标记为 `NOT VERIFIED`；如果缺失的是关键检查，则该 Phase 不得标记为通过。

当前生效的恢复计划为 `plans/000-recovery-master-plan.md`。
